# 2026-08-11

## Bug fix: 含空格的链接目标未渲染为真实链接
- 现象：Markdown 中链接目标文件名含空格（如 `09-Kotlin 重构决策与风险.md`）时，comrak 不解析为链接，渲染成纯文本；无空格的 `08-...` 正常。
- 根因：CommonMark 规定括号内裸链接目标不能含空格。
- 修复：在 `crates/md2x-core/src/converter.rs` 新增 `fix_spaced_link_destinations()`，对含空格且未用 `<>` 包裹的链接/图片目标自动用 `<>` 包裹（`[t](<url with space>)` 合法）。在 `convert_markdown_to_html`（HTML/PDF 路径）与 `docx/render.rs::render_body`（docx 路径）解析前调用。
- 细节：用 `split_inclusive('\n')` 精确保留换行；跳过围栏代码块（```）与行内代码（`...`），避免误改字面文本；仅新增 `regex = "1"` 依赖。
- 测试：converter.rs 与 docx/mod.rs 各加用例，全量 `cargo test -p md2x-core` 34 passed。
- 注意：docx 真实 URL 在 `.rels`（`content.links`），不在 `document_xml`。

## Bug fix: 点击内部 .md 链接会嵌套空页面
- 现象：GUI 预览中点击指向其他 .md 的链接，iframe 跳到一个无法渲染的空页面，而不是打开对应文件。
- 根因：模板 `templates/mpe.html` 有 `<base target="_self">`，链接默认在 iframe 内导航；相对路径解析到应用自身 URL，webview 无法渲染 → 空页。TOC 锚点靠自身 preventDefault 规避，普通 .md 链接没有。
- 修复：
  - `frontend/src/App.vue`：`loadPreview` 向 HTML 注入点击拦截脚本（仅拦截 `.md` 内部链接，锚点/外链放行），通过 `window.parent.postMessage` 通知父窗口；父窗口 `resolveAndOpen` 以当前文件目录为基准把相对路径解析为绝对路径，再调 `openMdFile` 在应用内打开；新增 `currentPath` 记录当前文件完整路径。
  - `crates/md2x-gui/src/lib.rs`：新增 `get_file_path` 命令（返回当前文件完整路径），供前端解析初始文件（双击 .md 打开）的相对链接；已在 `generate_handler!` 注册。
- 验证：`pnpm build` 通过；`cargo check -p md2x-gui` 通过。`get_file_path` 权限同 `get_file_name`（自定义命令默认允许，无需改 capability）。
